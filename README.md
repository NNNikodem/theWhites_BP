# Moja RPG Hra

Jednoduchá real-time RPG hra vyvíjaná v **Unity (C#)**. Hra obsahuje prológ príbehu rozdelený do 3 kapitol (máp) a je kompletene v **slovenskom jazyku**.

## 🎮 Hlavné mechaniky a vlastnosti
* **Real-time súbojový systém**
* **3 kapitoly / herné mapy**
* **Príbehový prológ a Quest systém**
* **Inventár a správa predmetov**
* **Leveling systém** (získavanie XP a rozdeľovanie skill pointov)
* **Save / Load systém** (ukladanie pozície)

## 🛠️ Použité technológie
* **Engine:** Unity
* **Jazyk:** C#

# My RPG Game

A simple real-time RPG game developed in **Unity (C#)**. The game features a story prologue divided into 3 chapters (maps) and is entirely in **Slovak**.

## 🎮 Main Mechanics and Features
* **Real-time combat system**
* **3 chapters / game maps**
* **Story prologue and quest system**
* **Inventory and item management**
* **Leveling system** (earning XP and allocating skill points)
* **Save/Load system** (saving your progress)

## 🛠️ Technologies Used
* **Engine:** Unity
